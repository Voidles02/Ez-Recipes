# EZ-Recipes

A **lightweight Paper plugin** that adds optimized and configurable crafting recipes for several useful Minecraft items.

> **Note:** EZ-Recipes is a **standalone plugin** and is completely independent from **The Soul System**.

## 🛠️ Features

EZ-Recipes provides custom crafting recipes for:

* 🍎 **Golden Apples**
* ✨ **Enchanted Golden Apples**
* 🪢 **Cobwebs**
* 🥕 **Golden Carrots**
* 💀 **Totems of Undying**

Recipes are designed to provide alternative crafting methods while keeping valuable items appropriately costly.

## ⚙️ Commands

### Admin Commands

```text id="j4l8qs"
/setup
```

Automatically configures and registers the plugin's optimized recipes, including the costly **Enchanted Golden Apple** and **Totem of Undying** recipes.

```text id="a7x2pm"
/status
```

Checks the plugin's current status and verifies that its systems are functioning correctly.

### Player Commands

```text id="m6q1zr"
/ez-show
```

Opens a GUI displaying all available EZ-Recipes and their crafting ingredients.

## 💾 Persistent Recipes

* Recipes are automatically saved to the plugin configuration.
* Configured recipes persist across **server restarts**.
* Prevents recipes from needing to be manually recreated after every restart.

## 🚀 Lightweight & Simple

EZ-Recipes is designed to be:

* Lightweight
* Easy to configure
* Simple to use
* Server-friendly
* Fully independent from other plugins
